# JC Ecuador Rides · Website

Bilingual (EN | ES) landing page for JC Ecuador Rides, a family-run private tour service in Quito, Ecuador.

**Live site:** https://jcecuadorrides.com

## What's inside

- `index.html` — tours page: 9 day trips from Quito, hover/tap previews, WhatsApp booking with pre-filled messages
- `privacy.html` — privacy policy (Ecuador LOPDP + GDPR-friendly)
- `consent.js` — cookie banner: GA4, Microsoft Clarity and Meta Pixel load only after consent (Google Consent Mode v2)
- `images/web/` — optimized WebP photos

## Stack

Plain HTML, CSS and JavaScript. No build step. Hosted on Cloudflare Pages.
